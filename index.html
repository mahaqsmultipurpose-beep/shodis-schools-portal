School Management & Billing Administrative Portal

Welcome to the integrated digital administration suite for Uncle Shodis Schools. This portal facilitates end-to-end academic broadsheet compilation, student report card generation with automated domain assessment, direct parent notifications, automated fee billing, payment tracking, expenditure logging, and real-time financial reporting.

🎓 Academic Performance

Generate cumulative broadsheets, automatic rank placements, and individual report cards with automated cognitive, affective, and psychomotor remarks.

🧾 Fees & Receipts

Issue serialized official school fee invoices, track installment payment histories, generate instant receipts, and calculate total balances due.

💳 Payments & Expenses

Input fee payments and school expenditures, manage staff payroll & payslips, with automatic updates across all relevant fields and financial reports.

🔒 Data Safety

Retrieve saved records at any time, and back up or restore every student, staff, billing and payment record on this device.

Data Safety: Backup & Restore

All student, billing, payment and expense records are saved automatically on this device/browser. On phones this storage can occasionally be cleared (e.g. if browsing data is cleared, or the file is opened from a different folder or app). To keep your records safe, regularly download a backup file below and keep it somewhere safe (e.g. Google Drive, email to yourself). You can restore it on this or any other phone/computer at any time.

📁 Default Backup Folder

On supported browsers (e.g. Chrome/Edge on desktop or Android) you can set a default folder once. Every future "Backup All Data" will then save straight into that same folder automatically, without a download prompt each time. If this browser doesn't support it, backups will simply keep downloading normally.

No default backup folder set - backups will download normally.
